# OpenPERouter VPN Setup - Deployment Package

This directory contains everything needed to deploy the OpenPERouter VPN setup on a real system.

## Contents

```
deployment/
├── usr/
│   └── local/
│       └── bin/
│           ├── setup-underlay.sh      # Underlay setup (NIC, VTEP)
│           ├── setup-network.sh       # Network infrastructure (VRF, bridges, VXLAN, veths)
│           ├── generate-config.sh     # Config generation (YAML with rawfrrconfigs)
│           └── common.sh              # Shared utilities
├── etc/
│   ├── systemd/
│   │   └── system/
│   │       ├── setup-underlay.service    # Systemd unit for underlay
│   │       ├── setup-network.service     # Systemd unit for network infra
│   │       └── generate-config.service   # Systemd unit for config
│   └── openperouter/
│       ├── templates/
│       │   └── openpe_evpn.yaml.template # YAML config template
│       └── vpn-setup.env.example         # Environment variables example
├── install.sh          # Installation script
├── uninstall.sh        # Uninstallation script
└── README.md           # This file
```

## Quick Start

### Installation

1. **Copy this directory to your target system:**
   ```bash
   scp -r deployment/ root@target-host:/tmp/openperouter-vpn-setup/
   ```

2. **SSH to the target system:**
   ```bash
   ssh root@target-host
   cd /tmp/openperouter-vpn-setup/
   ```

3. **Run the installer:**
   ```bash
   sudo ./install.sh
   ```

4. **Customize configuration:**
   ```bash
   sudo vi /etc/openperouter/vpn-setup.env
   ```
   
   Edit at minimum:
   - `UNDERLAY_NIC` - Your physical NIC name (e.g., ens3, enp0s1)
   - `TOR_IP` - Your TOR switch IP address
   - `TOR_AS` - Your TOR switch AS number
   - `LOCAL_AS` - Your local BGP AS number

5. **Ensure prerequisites:**
   ```bash
   # br0 bridge must exist with an IP address
   ip link show br0
   ip addr show br0
   
   # If missing, create it:
   ip link add br0 type bridge
   ip addr add 192.168.1.5/24 dev br0
   ip link set br0 up
   ```

6. **Enable and start services:**
   ```bash
   sudo systemctl enable setup-underlay.service setup-network.service generate-config.service
   sudo systemctl start setup-underlay.service setup-network.service generate-config.service
   ```

7. **Verify installation:**
   ```bash
   sudo systemctl status setup-underlay.service setup-network.service generate-config.service
   sudo journalctl -u setup-underlay.service -u setup-network.service -u generate-config.service
   cat /var/lib/openperouter/vpn-setup.vars
   cat /var/lib/openperouter/configs/openpe_evpn.yaml
   ```

### Uninstallation

```bash
cd /tmp/openperouter-vpn-setup/
sudo ./uninstall.sh
```

## Service Dependencies

```
routerpod-pod.service (FRR Container)
         ↓
setup-underlay.service (Move NIC, derive VTEP IP, save variables)
         ↓
setup-network.service (Create VRFs, bridges, VXLAN, veths)
         ↓
generate-config.service (Generate YAML with rawfrrconfigs)
         ↓
OpenPERouter Controller (Apply rawfrrconfigs to FRR)
```

**Note**: With setup-network.service creating all infrastructure, the controller only needs to apply the FRR configuration from rawfrrconfigs. The network infrastructure (VRFs, bridges, VXLAN, veth pairs) is already created by the scripts.

## Configuration

All configuration is done via `/etc/openperouter/vpn-setup.env`:

### Essential Settings

```bash
# Physical NIC for underlay (required)
UNDERLAY_NIC=eth1

# TOR switch configuration (required)
TOR_IP=10.1.1.254
TOR_AS=65000
LOCAL_AS=64514
```

### VPN Settings (optional, defaults provided)

```bash
VRF_NAME=red
L3_VNI=100
L2_VNI=210
VXLAN_PORT=4789
L2_GATEWAY_IP=192.168.110.1/24
```

### Advanced Settings (optional)

```bash
FRR_READY_TIMEOUT=60
NODE_NAME=$(hostname)
```

## Troubleshooting

### What Gets Created

**setup-underlay.service** creates:
- Moves underlay NIC (eth1) to FRR namespace
- Derives VTEP IP from br0 (e.g., 192.168.1.5 → 10.0.0.5)
- Saves variables to `/var/lib/openperouter/vpn-setup.vars`

**setup-network.service** creates (in FRR namespace):
- VRF `red` (routing table 200)
- L3VNI bridge `br-pe-100` (enslaved to VRF)
- L3VNI VXLAN interface `vni100` (enslaved to bridge)
- L2VNI bridge `br-pe-210` (enslaved to VRF, has gateway IP)
- L2VNI VXLAN interface `vni210` (enslaved to bridge)
- Veth pair `host-210` (on host br0) ↔ `pe-210` (on FRR br-pe-210)

**generate-config.service** creates:
- YAML configuration at `/var/lib/openperouter/configs/openpe_evpn.yaml`
- Includes rawfrrconfigs with complete FRR EVPN configuration

### Check Service Status

```bash
systemctl status setup-underlay.service
systemctl status setup-network.service
systemctl status generate-config.service
```

### View Logs

```bash
# Recent logs
journalctl -u setup-underlay.service -u generate-config.service --no-pager

# Follow logs in real-time
journalctl -u setup-underlay.service -u generate-config.service -f

# Only errors
journalctl -u setup-underlay.service -u generate-config.service -p err
```

### Check Generated Files

```bash
# Variables from underlay setup
cat /var/lib/openperouter/vpn-setup.vars

# Generated YAML configuration
cat /var/lib/openperouter/configs/openpe_evpn.yaml

# Preview rawfrrconfigs section
grep -A 50 "rawfrrconfigs:" /var/lib/openperouter/configs/openpe_evpn.yaml
```

### Common Issues

**Problem**: `setup-underlay.service` times out waiting for FRR

**Solution**:
```bash
# Check FRR container
podman ps | grep frr
podman logs frr

# Check routerpod service
systemctl status routerpod-pod.service
```

---

**Problem**: `br0 bridge does not exist`

**Solution**:
```bash
# Create br0 bridge
ip link add br0 type bridge
ip addr add 192.168.1.5/24 dev br0  # Use your network's IP
ip link set br0 up
```

---

**Problem**: `Host NIC eth1 not found`

**Solution**:
```bash
# List available NICs
ip -br link show

# Update /etc/openperouter/vpn-setup.env with correct NIC name
UNDERLAY_NIC=ens3  # or whatever your NIC is called
```

---

**Problem**: Configuration generated but controller not applying it

**Solution**:
```bash
# Check controller is running
systemctl status perouter.service  # or equivalent

# Check controller can read the config directory
ls -la /var/lib/openperouter/configs/

# Check controller logs
journalctl -u perouter.service
```

### Verify Network Infrastructure

After setup-network.service completes, verify infrastructure in FRR namespace:

```bash
# Check VRF
podman exec frr ip link show type vrf

# Check bridges
podman exec frr ip link show type bridge

# Check VXLAN interfaces
podman exec frr ip link show type vxlan

# Check veth pair
ip link show host-210
podman exec frr ip link show pe-210

# Check br0 attachment
bridge link show | grep host-210
```

### Manual Service Control

```bash
# Restart just config generation (doesn't touch infrastructure)
systemctl restart generate-config.service

# Restart network infrastructure (doesn't touch underlay)
systemctl restart setup-network.service generate-config.service

# Restart all services
systemctl restart setup-underlay.service setup-network.service generate-config.service

# Stop services
systemctl stop generate-config.service setup-network.service setup-underlay.service

# Disable from boot
systemctl disable setup-underlay.service setup-network.service generate-config.service
```
